## The slogan

> Solana in your pocket, an agent on your side — it moves your money before you even ask.

## How it works

`main.py` writes that single slogan — one line, 18 words, 87 characters —
to `/output/entry.txt`. It validates the competition gate first (1–140
characters, at most 20 words, single line, no leading/trailing whitespace)
and writes the file with no trailing newline, so the two grading runs are
byte-identical.

```sh
python3 main.py
cat /output/entry.txt
```
